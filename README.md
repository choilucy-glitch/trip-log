# 우리 여행 기록 (trip-log)

함께 다닌 여행을 계속 쌓아가는 웹앱이에요. 여행마다 일정·예약·바우처·가계부·사진·체크리스트를 따로 관리하고, 폰에서 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

- 여행 목록: 다가오는 여행 / 지난 여행
- 일정: 날짜별 타임라인, 앱에서 바로 추가·수정 (구글맵·길찾기 자동)
- 예약 정보·바우처, 원화/엔화 가계부와 정산, 날짜별 사진, 출발 전 체크리스트
- 여행마다 초대한 이메일만 볼 수 있음 (Firebase 로그인 + `firestore.rules.example` 참고)

데이터는 Firestore `trips/{여행}` 아래에 저장되고, 이 저장소에는 화면 코드만 있어요.
